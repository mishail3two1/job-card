Карточка вакансии (Job Card)

Учебная работа по дисциплине «Разработка интернет-приложений»: вёрстка одной карточки вакансии по макету из Figma.

Макет
- Источник: [Job Cards в Figma Community](https://www.figma.com/community/file/1179301541629020534/job-cards)
- Автор: ИМЯ АВТОРА С ЕГО СТРАНИЦЫ ([@muktiray](https://www.figma.com/@muktiray))
- Лицензия: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.ru)
- Изменения: из макета взята одна карточка из девяти, текст переведён на русский, макет сверстан в HTML и CSS. Автор макета эти изменения не проверял и не одобрял.


Из макета сверстана одна карточка (вакансия «Стажёр по продуктовому дизайну»).

Технологии
HTML5, семантическая разметка
CSS3, переменные (:root)
Методология БЭМ
Flexbox
Шрифт Roboto (Google Fonts)
БЭМ-структура
Блок job-card: элементы top, logo, logo-img, verified, bookmark, bookmark-icon, title, company, location, tags, footer, date, applicants
Модификатор job-card__bookmark--active: вакансия сохранена
Отдельный блок tag: тег вакансии

Запуск

Откройте index.html в браузере или запустите через расширение Live Server в VS Code.

Проверка

HTML и CSS проверены валидатором W3C (Nu Html Checker и Jigsaw): ошибок и предупреждений нет.
